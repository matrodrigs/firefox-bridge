# Firefox Bridge — source review

This is the source submission for the initial **0.1.0** release, extension ID `firefox-bridge@matrodrigs`. The unsigned XPI and this source archive are generated from the same checkout. The public release is withheld until Mozilla signs the extension.

## Reproduce the extension

Extract the source archive and open a terminal in its `firefox-bridge` directory. Install [Node.js](https://nodejs.org/en/download) **24.15.0**, which includes npm **11.17.0**. The submitted build is produced on Windows; the build commands also run on Ubuntu and use no Windows-only build steps.

```sh
npm ci
npm run build
npm run lint:extension
npm run package
```

Compare the contents of `artifacts/Firefox-Bridge-0.1.0-unsigned.xpi` with the submitted XPI. `extension/background.js` and `extension/panel.js` are generated by esbuild **0.28.2** from `src/background.mjs` and `src/panel.mjs`. Build tools and dependencies are pinned in `package-lock.json`. No secrets, signing credentials, native host installation, Firefox profile, or running MCP client are needed to reproduce these files.

The archive includes the complete source, lockfile, build script, native host, and documentation. It excludes `node_modules`, generated bundles, local credentials, test profiles, and logs. `npm ci` downloads public dependencies from npm; the build itself performs no network requests and does not minify or obfuscate application logic.

## Runtime overview

The extension exposes fixed browser operations to a local MCP client through Firefox Native Messaging. The separately installed Node host connects to a loopback-only broker. It is restricted to this extension ID and is registered per user by `scripts/setup.mjs`; setup is needed to exercise the native connection, but not to review or reproduce the extension.

The panel starts paused and controls access by exact site origin. Broad host permissions support user-authorized page reading, interaction, screenshots, and navigation. Downloads, uploads, and debug collection have separate grants. The extension has no telemetry endpoint, remote executable code, or arbitrary JavaScript evaluation tool. Console instrumentation runs fixed code in the page world and treats the result as untrusted page content.
